# Echo's World 🐾

歡迎來到 **Echo's World**！這是一個專為狗狗 **Echo** 打造的充滿活力與溫馨的個人靜態網頁，記錄了 Echo 的日常萌照、生活怪癖以及與大家的互動。

## 🌟 網頁特色

- **響應式設計 (RWD)：** 無論使用手機、平板或電腦瀏覽，都能完美呈現。
- **趣味互動功能：**
  - **摸摸 Echo 🐾：** 點擊按鈕可以幫 Echo 累積摸摸次數，並有可愛的動態特效！
  - **即時留言板：** 訪客可以留下想對 Echo 說的話，提交後會即時顯示在頁面上。
- **豐富區塊：** 包含 Hero 主視覺、關於 Echo、生活寫真牆、日常怪癖與留言板。

## 🛠️ 使用技術

- **HTML5** - 網頁結構
- **CSS3** - 視覺樣式與 RWD 響應式排版（採用 CSS Variables、Flexbox & Grid）
- **JavaScript (Vanilla)** - 互動邏輯（計數器、浮動動畫、即時留言處理）

## 📁 檔案結構

```text
echo-website/
├── index.html     # 網頁主結構與內容
├── style.css      # 視覺設計與手機版面適配
├── script.js      # 互動邏輯與留言功能
└── README.md      # 專案說明文件
```

## 🚀 如何本地預覽與部署

1. **本地預覽：**
   將所有檔案下載至同一個資料夾，雙擊 `index.html` 即可在瀏覽器中開啟。

2. **部署到 GitHub Pages：**
   - 建立一個公開的 GitHub Repository（例如 `echo-website`）。
   - 將 `index.html`、`style.css`、`script.js` 與此 `README.md` 上傳至儲存庫。
   - 前往專案的 **Settings > Pages**。
   - 在 **Build and deployment** 的 Branch 選擇 `main`（或 `master`），資料夾選 `/ (root)`，點擊 **Save**。
   - 等待數分鐘後，即可透過產生的 GitHub Pages 網址訪問網站！
